# Rebufo en vivo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Etiquetar en vivo cada vuelta como en tren (`≋`), bloqueada (`▮`) o limpia; excluir las etiquetadas de la calidad del kart y de la media de pista; mostrar glifo + tooltip y "Rebufo hoy".

**Architecture:** Motor puro `src/en-traffic.js` (IIFE dual navegador/CommonJS) alimentado por el callback `onLap` del parser Apex desde los conectores (directo y replay, este con el reloj del log). `en-state.js` consulta el motor con un filtro con red de seguridad; `en-columns.js`/`en-grid.js` pintan el glifo; `en-advanced.js` añade la línea al popup de Media pista.

**Tech Stack:** JavaScript vanilla, tests Node puros con `assert` (`node tests/<f>.test.js`).

**Spec:** `docs/superpowers/specs/2026-09-29-rebufo-design.md`

## Global Constraints

- Umbrales: `GAP_MIN=0.2`, `TRAIN_MAX=1.2`, `BLOCK_FROM=1.5`, `BLOCK_TO=0.6`, `MIN_GIFT_N=100` (segundos / vueltas).
- Red de seguridad: si tras quitar vueltas etiquetadas quedan < 3, se usan todas.
- Tiempos mostrados en formato m:ss.sss (`_enFmt`).
- No tocar tendencia, consistencia, M5 mostrada, mejor vuelta ni tiempos oficiales.
- Contraste: el glifo usa `#9ca3af` (ya validado como texto sobre el cristal).
- Nada de push/deploy sin confirmación explícita del usuario.
- Suite completa: `for f in tests/*.test.js; do node "$f" >/dev/null 2>&1 && echo "OK $f" || echo "FALLO $f"; done`
